# Dawnhold

Mobile-first 3D zombie base-defense game (Three.js, single HTML file).

Play: GitHub Pages deploys automatically from `main` (see `.github/workflows/pages.yml`).
Progress saves in your browser (localStorage), so a reload continues from the start of your current day.

Build the browser zips locally: `python3 tools/build_web.py` (writes `dist/`).
Models: Kenney (CC0), see `assets/CREDITS.txt`.
